# Свадебное приглашение — Жасур и Мадина

Интерактивный вертикальный сайт-приглашение в бирюзово-золотой стилистике.

## Возможности

- анимированный конверт;
- музыка из предоставленного видео;
- календарь и программа дня;
- адрес и кнопка карты;
- обратный отсчёт;
- дресс-код;
- анкета гостя;
- адаптация для телефона и ноутбука.
